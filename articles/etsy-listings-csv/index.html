How do I download my Etsy listings as a file, and what is in it?

Last checked: 16 November 2026.

In Shop Manager, go to Settings, then Options, then Download Data, and choose Download CSV. The file lists your active listings with their titles, descriptions, prices and a few other fields.

Where to find it

Etsy's help page, "How to Download Your Listing Information", gives the steps:

  1. Sign in to Etsy.com.
  2. Click You, then Shop Manager.
  3. Click Settings, then Options.
  4. Click Download Data.
  5. Click Download CSV to save the file to your computer.

What the file contains

Etsy says the file includes, for your active listings:

  • Title
  • Description
  • Price
  • Currency code
  • Quantity
  • Tags
  • Materials
  • Image URLs
  • SKU numbers, if you have added any

What it does not contain

  • Listings that are not active. Drafts, sold-out and expired listings are not included.
  • Variations and their prices. Etsy's list of fields does not mention them. If a listing has options at different prices, expect to add those prices yourself to any sheet you build from the file.
  • Anything about orders or customers. Those are separate downloads.

Opening it in a spreadsheet without breaking it

A CSV file is plain text, and spreadsheet programs like to "help" when they open one.

  • Keep the original file untouched and work on a copy.
  • If accented letters or symbols look wrong, import the file and choose UTF-8 as its encoding instead of double-clicking it.
  • Watch for long numbers or codes being turned into dates or rounded. Importing those columns as text prevents it.
  • Descriptions contain line breaks. Rows may look taller than you expect; that is normal.

Etsy notes that the format "can be imported into most spreadsheet applications, including Excel, Numbers, and Google Spreadsheets."

What you can do with it

  • Keep a dated backup of your listings.
  • Build a price sheet: one row per listing, with a column for a US price. The sum to use.
  • Check for listings with no materials filled in. Materials help when you look up a tariff code.
